# 로컬(Local)과 원격(Remote) 저장소

## 1. 개념 정리

| 구분 | 설명 |
|---|---|
| **로컬(Local)** | 내 컴퓨터에 있는 저장소 |
| **원격(Remote)** | GitHub에 있는 저장소 |

## 2. 구조 도식화

```mermaid
flowchart LR
    A[💻 로컬 저장소<br/>내 컴퓨터] <--> |파일 공유| B[☁️ 원격 저장소<br/>GitHub]
```

## 3. 활용 예시

```mermaid
flowchart LR
    A[🏠 집 컴퓨터] <--> B[☁️ GitHub<br/>원격 저장소]
    B <--> C[💻 다른 장소의 컴퓨터]
```

GitHub에 로그인하면 다른 장소에서도 저장한 파일에 접근할 수 있다.

## 4. 핵심 요약

- **로컬** = 내 컴퓨터에 저장
- **원격** = GitHub에 저장
- GitHub를 이용하면 파일을 메일로 따로 옮기지 않아도 다른 장소에서 쉽게 확인하고 관리할 수 있다.
