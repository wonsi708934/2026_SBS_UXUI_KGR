## ③ 핵심 개념 설명

### HTML과 CSS의 차이

- **HTML(HyperText Markup Language)**: 화면에 무엇을 놓을지 구조와 내용을 지정합니다.
- **CSS(Cascading Style Sheets)**: HTML 요소의 크기, 색상, 배치 등 외형을 지정합니다.

| 코드/용어 | 읽는 법 | 역할 |
|---|---|---|
| `DOCTYPE` | 독타입 | HTML 문서 형식 선언 |
| `lang` | 랭 | 문서의 주 언어 지정 |
| `title` | 타이틀 | 브라우저 탭 제목 |
| `link` | 링크 | 외부 CSS 파일 연결 |
| `div` | 디브 | 별도의 의미가 없는 묶음 영역 |
| `class` | 클래스 | 요소에 재사용 가능한 이름 부여 |
| `.top-banner` | 닷 탑 배너 | 클래스를 지정하는 CSS 선택자 |
| `height` | 하이트 | 높이 지정 |
| `background-color` | 백그라운드 컬러 | 배경색 지정 |
| `px` | 픽셀 | CSS 길이 단위 |
| `#5F0080` | 헥스 색상 코드 | 보라색을 표현하는 색상값 |

### AI를 활용하더라도 코드를 이해해야 하는 이유
강사는 AI 에이전트가 코드를 빠르게 생성할 수 있다고 설명하면서도, 사람이 결과를 검수할 줄 알아야 한다고 강조했습니다.

- **웹 표준**: 정해진 규칙에 맞는 HTML/CSS 작성
- **웹 접근성**: 더 다양한 이용자가 사용할 수 있는 화면 만들기
- **성능**: 이미지와 코드 용량을 적절히 줄이고 불필요한 요소 방지
- **검수**: AI가 만든 코드의 문제를 발견하고 개선할 수 있는 능력

**강사 강조:** 초기에는 클래스명 추천과 정보 확인을 AI에 맡길 수 있지만, 과제 전체를 AI가 대신 구현하도록 하지 말고 직접 코드를 작성해 보세요.

## ④ VS Code에서 코드 작성하기

### STEP 1. Live Server 실행

**작업 위치:** VS Code의 왼쪽 탐색기(Explorer)

1. 실습 폴더를 VS Code에서 엽니다.
2. `index.html`을 찾아 마우스 오른쪽 버튼으로 클릭합니다.
3. **Open with Live Server**를 선택합니다.
4. 브라우저가 열리면 그대로 둡니다.

**Live Server**는 로컬 웹페이지를 브라우저에서 미리 보고 저장 후 변경사항을 쉽게 확인하게 해 주는 VS Code 확장입니다.

메뉴가 없을 때는 왼쪽 **Extensions(확장)** 메뉴에서 `Live Server`가 설치되어 있는지 확인하세요. 설치했는데도 실행할 수 없다면 HTML 파일을 열고 아래쪽 `Go Live` 버튼이 있는지 확인하거나 VS Code를 다시 시작합니다.

### STEP 2. Emmet으로 HTML 기본 틀 생성

**작업 파일:** `index.html`  
**커서 위치:** 비어 있는 파일의 첫 번째 줄

1. 느낌표 `!`를 입력합니다.
2. HTML 기본 구조를 만드는 자동완성 제안을 선택합니다.
3. `Tab` 또는 `Enter`를 눌러 확장합니다.

결과 예시:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>
```

> VS Code 버전·설정에 따라 들여쓰기나 기본 내용이 조금 다를 수 있습니다.

| 코드 | 뜻 |
|---|---|
| `<!DOCTYPE html>` | HTML 문서 선언 |
| `<html>` | 전체 HTML 문서의 시작 |
| `<head>` | 문서 설정과 메타데이터를 작성하는 공간 |
| `<meta charset="UTF-8">` | 문자를 UTF-8로 해석하도록 지정 |
| `<meta name="viewport" ...>` | 모바일 화면 너비와 초기 배율 설정 |
| `<title>` | 브라우저 탭 제목 |
| `<body>` | 웹페이지에 나타나는 내용 작성 |

**Emmet 입력 연습**: `index.html`에서 `!`를 입력하고 `Tab`으로 전체 HTML 구조를 생성해 보세요.

### STEP 3. AI에게 한국어 언어 설정 요청
1. `index.html`의 `<html lang="en">` 줄을 찾습니다.
2. 해당 줄을 선택하고 `Ctrl + C`로 복사합니다.
3. AI 에이전트 입력창에 붙여 넣습니다.
4. 다음처럼 질문합니다.

```text
다음 HTML 태그의 문서 언어를 한국어로 바꾸는 방법을 알려줘.
<html lang="en">
```

변경 전:

```html
<html lang="en">
```

변경 후:

```html
<html lang="ko">
```

| 언어 코드 | 언어 |
|---|---|
| `en` | 영어 |
| `ko` | 한국어 |
| `ja` | 일본어 |
| `zh` | 중국어 |

**[초보자를 위한 추가 설명]** `lang`은 번역 기능이 아닙니다. 문서의 주 언어를 브라우저와 보조 기술 등에 알려주는 설정입니다.

### STEP 4. 브라우저 제목 바꾸기

**작업 파일:** `index.html`  
**커서 위치:** `<head>` 안의 `<title>` 요소

기존:

```html
<title>Document</title>
```

수정:

```html
<title>마켓컬리 와이어프레임</title>
```

1. `Document` 글자만 선택합니다.
2. `마켓컬리 와이어프레임`을 입력합니다.
3. `Ctrl + S`로 저장합니다.
4. 브라우저 탭 제목이 바뀌었는지 확인합니다.

**Windows 단축키:**

| 단축키 | 기능 |
|---|---|
| `Ctrl + C` | 복사 |
| `Ctrl + V` | 붙여넣기 |
| `Ctrl + X` | 잘라내기 |
| `Ctrl + Z` | 실행 취소 |
| `Ctrl + S` | 저장 |
| `Shift + 방향키` | 커서부터 텍스트 선택 |
| `Shift + Home` | 커서 위치에서 현재 줄 시작 방향으로 선택 |
| `Shift + End` | 커서 위치에서 현재 줄 끝 방향으로 선택 |
| `Ctrl + /` | 주석 처리/해제(언어에 따라 다름) |

**주의:** 태그까지 함께 지우지 않도록 `Document` 텍스트만 바꿉니다.

### STEP 5. CSS 파일 연결

**예시 폴더 구조**

```text
마켓컬리-실습/
├── index.html
└── style1.css
```

1. `style1.css` 파일이 있는지 확인하고 없다면 생성합니다.
2. `index.html`로 돌아갑니다.
3. `<head>` 안, `<title>` 아래에 커서를 놓습니다.
4. `link` 또는 `link:css`를 입력하고 CSS 링크 자동완성을 선택합니다.
5. `Tab` 또는 `Enter`로 확장한 뒤, `href`에 `style1.css`를 적습니다.

```html
<link rel="stylesheet" href="style1.css">
```

| 부분 | 의미 |
|---|---|
| `<link` | 외부 리소스 연결용 요소 |
| `rel="stylesheet"` | 연결할 리소스가 CSS 스타일시트라는 뜻 |
| `href="style1.css"` | CSS 파일의 위치(경로) |
| `>` | HTML 태그 종료 |

`href`의 파일명과 실제 파일명이 정확히 같아야 합니다. CSS가 `css` 하위 폴더에 있으면 `href="css/style1.css"`처럼 경로를 작성합니다.

> 실제 수업 프로젝트 파일명이 다르다면 그 이름에 맞춰 연결해야 합니다.

## ⑤ 개발자 도구로 마켓컬리 구조 조사

### STEP 6. F12로 개발자 도구 열기

1. 브라우저에서 마켓컬리 웹사이트를 엽니다.
2. `F12`를 누릅니다. 노트북 키보드 설정에 따라 `Fn + F12`가 필요할 수 있습니다.
3. 개발자 도구에서 **화살표가 있는 요소 선택 아이콘(Inspect element)**을 누릅니다.
4. 웹페이지 최상단의 보라색 배너를 클릭합니다.
5. **Elements** 탭에서 해당 HTML 요소를 확인합니다.

**마우스 대체 방법:** 페이지를 오른쪽 클릭한 뒤 `검사(Inspect)`를 선택할 수도 있습니다.

### STEP 7. 클래스명 조사 후 AI에게 이름 질문

예를 들어 개발자 도구에 다음 코드가 있다고 가정합니다.

```html
<div class="example-banner">...</div>
```

`example-banner`는 설명을 위한 **가상 클래스명**이며 실제 사이트에서 확인된 이름은 아닙니다.

1. 찾은 요소의 `class` 부분을 확인합니다.
2. 클래스 이름을 선택하고 `Ctrl + C`로 복사합니다.
3. AI 에이전트 입력창에 붙여 넣습니다.
4. 다음처럼 질문합니다.

```text
마켓컬리 사이트에서 이 클래스에 해당하는 구간을
웹디자인에서 보통 뭐라고 부르나요?
```

강사님은 해당 영역을 **최상단 프로모션 배너**, **탑 배너**, 수업 중에는 **탑 팝업**으로도 불렀습니다. 팝업과 배너는 엄밀하게 다른 형태일 수 있으므로 이번 교재에서는 **탑 배너**로 통일합니다.

### STEP 8. 높이 및 배경색 확인

AI에게 다음과 같이 물어봅니다.

```text
이 마켓컬리 탑 배너의 높이 값과 배경색을 알려줘.
높이는 px로, 색상은 HEX 코드로 알려줘.
```

| 항목 | 값 | 근거/주의 |
|---|---|---|
| 높이 | `42px` | 강사가 직접 말함 |
| 배경색 | `#5F0080` | 음성 인식 `5 OF0080`을 CSS 색상 문맥으로 보정 |
| 클래스 이름 | 본 교재는 `top-banner` 사용 | |

**HEX와 RGB의 비교**

```css
background-color: #5F0080;
background-color: rgb(95, 0, 128);
```

두 선언은 같은 색입니다. `#`로 시작하는 HEX 코드는 16진수로 색을 표현합니다.

## ⑥ 탑 배너 HTML·CSS 직접 작성

### STEP 9. AI에게 클래스명 추천받기

```text
마켓컬리 웹사이트 최상단 프로모션 배너의
가장 짧고 직관적인 CSS 클래스명을 추천해 줘.
```

강의에는 `탑밴` 등으로 들리는 표현이 있지만 정확한 영문 표기가 남아 있지 않습니다. 본 교재는 일관성을 위해 **`top-banner`**를 사용합니다.

### STEP 10. HTML에서 배너 영역 생성

**작업 파일:** `index.html`  
**커서 위치:** `<body>`의 여는 태그와 닫는 태그 사이

1. `<body>` 아래 빈 줄에 커서를 놓습니다.
2. 다음 Emmet 약어를 입력합니다.

```text
div.top-banner
```

3. `Tab` 또는 `Enter`로 자동완성을 선택합니다.
4. 다음 HTML이 생성되었는지 확인합니다.

```html
<div class="top-banner"></div>
```

**문법 분석**

- `div`: HTML 태그 이름
- `.`: Emmet에서 클래스를 지정하는 기호
- `top-banner`: 지정할 클래스 이름
- `class="top-banner"`: 해당 요소의 HTML 클래스 속성
- `</div>`: `div` 요소의 닫는 태그

참고로 `div`는 별도의 의미가 없는 일반적인 묶음 요소입니다. 실제 의미가 정해진 콘텐츠라면 상황에 맞는 시맨틱 HTML 태그가 더 적합할 수 있습니다.

### STEP 11. CSS 클래스 선택자 생성

**작업 파일:** `style1.css`  
**커서 위치:** 파일 첫 번째 줄(비어 있는 파일 기준)

```css
.top-banner {

}
```

- HTML: `class="top-banner"`
- CSS: `.top-banner`

CSS에서 앞의 **점(`.`)**은 클래스 선택자임을 뜻합니다. 중괄호 `{ }` 안에 해당 요소에 적용할 CSS 선언을 작성합니다.

### STEP 12. 높이 42px 지정

**작업 파일:** `style1.css`  
**입력 위치:** `.top-banner`의 중괄호 안

```css
.top-banner {
    height: 42px;
}
```

`height: 42px;`의 구성:

- `height`: 속성 이름
- `:`: 속성과 값을 구분하는 콜론
- `42`: 숫자
- `px`: CSS 픽셀 단위
- `;`: CSS 선언의 끝

### STEP 13. 배경색 설정

같은 중괄호 안에 두 번째 선언을 작성합니다.

```css
.top-banner {
    height: 42px;
    background-color: #5F0080;
}
```

저장(`Ctrl + S`) 후 브라우저를 확인합니다.

### STEP 14. 임시 문구 넣기

**작업 파일:** `index.html`  
**커서 위치:** `div`의 여는 태그와 닫는 태그 사이

수정 전:

```html
<div class="top-banner"></div>
```

수정 후:

```html
<div class="top-banner">안녕하세요</div>
```

## ⑧ 오류 해결

강의에서는 일부 학생이 화면과 색상이 다르게 표시되는 문제를 겪었습니다. 강사는 코드를 캡처해 공유하게 하고 자신의 코드와 비교하여 수정하도록 했습니다.

### 오류 1. 배경색이 안 보여요

1. `index.html`에 CSS 파일 연결 코드가 있는지 확인
2. `href`와 실제 CSS 파일명이 같은지 확인
3. HTML의 `class` 이름과 CSS의 `.클래스이름`이 같은지 확인
4. 중괄호·콜론·세미콜론 등 문법 확인
5. 두 파일 모두 `Ctrl + S`로 저장 후 브라우저 새로고침

```html
<link rel="stylesheet" href="style1.css">
```

HTML:

```html
<div class="top-banner"></div>
```

```css

    height: 42px;
    background-color: #5F0080;

```

`banner`의 `n`이 하나 빠져 서로 다른 이름이 되었습니다. CSS를 `.top-banner`로 수정합니다.

### 오류 3. 콜론을 빠뜨렸어요

잘못된 코드:

```css
background-color #5F0080;
```

정상 코드:

```css
background-color: #5F0080;
```

잘못된 코드:

```css
.top-banner {
    height: 42px;
```

```css
}
```

```css

```

- `.top-banner` : `top-banner` 클래스를 가진 요소 선택

- `:` : CSS 속성과 값 구분
- `;` : CSS 선언 종료

> **정확성 안내:** `#5f0080`은 학습용 배경색 예시입니다. 이전 수업에서 사용한 배경색이 이미 있다면 그대로 유지하세요.

```css
/* 글자 색상 */
color: #fff;
```

### 실습 2. 배너 글자를 가로·세로 중앙 정렬

강사님의 핵심 질문: **“우리가 지금 움직이려는 게 뭐예요?”** → 텍스트입니다. 그러므로 텍스트를 감싼 부모인 `.top-banner`에 Flexbox를 적용합니다.

`.top-banner`의 기존 선언 아래에 작성합니다.

```css
display: flex;
justify-content: center;
align-items: center;
```

완성 형태:

```css
.top-banner {
  background-color: #5f0080;
  color: #fff;
  display: flex;
  justify-content: center;
  align-items: center;
}
```

| CSS 코드 | 의미 |
|---|---|
| `display: flex;` | 자식 요소를 Flexbox 방식으로 배치 |
| `justify-content: center;` | 주축 방향에서 중앙 정렬 |
| `align-items: center;` | 교차축 방향에서 중앙 정렬 |

**초보자를 위한 추가 설명:** `justify-content`가 항상 가로 방향인 것은 아닙니다. `flex-direction: column`일 때는 주축이 세로 방향이 됩니다.

**직접 실험:** 아래 값을 `.top-banner`에 하나씩 바꾸어 입력하고 저장한 뒤 화면을 관찰하세요.

```css
/* 실험 A: 주축의 시작 */
justify-content: flex-start;

/* 실험 B: 중앙 */
justify-content: center;

/* 실험 C: 주축의 끝 */
justify-content: flex-end;
```

세 가지를 확인한 뒤 수업 값인 `center`로 되돌립니다.

### 실습 3. 글자 크기 14px 적용

`.top-banner` 안에 다음 줄을 추가합니다.

```css
font-size: 14px;
```

- `font-size` : 글자 크기
- `14px` : CSS 픽셀 단위 글자 크기

### 실습 4. Pretendard 웹폰트 연결

강의에서는 [눈누](https://noonnu.cc/)를 이용했습니다.

1. 웹 브라우저에서 눈누에 접속합니다.
2. 무료 폰트 목록에서 **Pretendard**를 찾습니다.
3. 폰트 상세 페이지의 **웹폰트 사용** 항목을 엽니다.
4. 코드를 선택하고 `Ctrl + C`로 복사합니다.
5. VS Code의 `style.css` 파일로 돌아옵니다.
6. CSS 맨 위에 커서를 놓고 `Ctrl + V`로 붙여 넣습니다.

> 이미 눈누의 코드를 붙였다면 아래 대체 코드를 중복 추가하지 마세요.

**초보자를 위한 추가 설명 — 다른 연결 방식 예시:**

```css
@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css");
```

위 코드는 외부 스타일시트를 불러오는 `@import` 방식입니다. 일반 CSS 규칙보다 먼저 두어야 합니다.

이어서 `body` 선택자를 작성합니다.

```css
body {
  font-family: "Pretendard", sans-serif;
}
```

| 코드 | 설명 |
|---|---|
| `body` | 페이지 콘텐츠를 담는 HTML 요소 |
| `font-family` | 사용할 글꼴 지정 |
| `"Pretendard"` | 첫 번째 글꼴 후보 |
| `,` | 후보 글꼴 구분 |
| `sans-serif` | 대체용 고딕 계열 글꼴 |

**중요:** 웹폰트 코드로 글꼴을 **연결**하는 것과 `font-family`로 글꼴을 **적용**하는 것은 별개입니다.

HTML 구조도 복습하세요.

```text
html
├─ head  : 문서 제목, 메타 정보, CSS 연결 등
└─ body  : 웹페이지에 표시되는 콘텐츠
```

`body`에 글꼴을 지정하면 많은 자식 요소가 글꼴을 상속받지만, 자식에 별도의 `font-family`가 있으면 그 설정이 우선할 수 있습니다.

### 실습 5. 개발자 도구로 유틸리티 메뉴 조사

분석할 메뉴: **회원가입 · 로그인 · 고객센터**

1. 브라우저에서 참고할 사이트를 엽니다.
2. `F12` 또는 `Ctrl + Shift + I`를 눌러 개발자 도구를 엽니다.

**AI 권한 주의:** 강의 중에는 문제 해결을 위해 `Full Access`가 언급되었지만, 모든 학습 작업에 필요한 것은 아닙니다. 에이전트가 파일을 바꾸거나 명령을 실행할 수 있으므로 작업 폴더와 권한 범위를 먼저 확인하세요.

### 실습 6. 유틸리티 메뉴 박스 생성

1. `index.html`을 엽니다.
2. `<body>` 안의 기존 `.top-banner`를 찾습니다.
3. **상단 배너 닫는 `</div>` 다음 줄**에 커서를 놓습니다.
4. 다음 Emmet 문법을 입력합니다.

```text
div.utility-menu
```

5. `Tab`을 눌러 태그를 생성합니다.

```html
<div class="utility-menu"></div>
```

6. 임시로 `테스트`라는 글자를 작성합니다.

```html
<div class="utility-menu">
```


**`border` 설명:**


> 같은 선택자 안에 이 세 줄을 동시에 유지하지 말고 **한 번에 하나만 적용**해서 비교하세요.

### 실습 8. 너비 1050px 컨테이너 만들기

1. `index.html`의 `.utility-menu` 안에 있는 `테스트`를 지웁니다.
2. 그 자리에 `div.con`을 입력하고 `Tab`을 누릅니다.

```html
<div class="utility-menu">
  <div class="con"></div>
</div>
```

3. `style.css`의 `.utility-menu` 규칙 아래에 다음 코드를 작성합니다.

```css
.con {
  border: 1px solid orange;
  width: 1050px;
}
```

4. `width: 1050px;` 아래에 양쪽 여백을 추가합니다.

```css
margin-left: auto;
margin-right: auto;
```

- `width: 1050px` : 콘텐츠 너비 지정
- `margin-left: auto` : 사용 가능한 왼쪽 여백 자동 계산
- `margin-right: auto` : 사용 가능한 오른쪽 여백 자동 계산
- 양쪽 여백을 자동 계산하면 남는 공간이 양쪽에 배분되어 가운데 정렬할 수 있습니다.

**초보자를 위한 추가 설명:** 강사님은 `.con`과 같은 내부 콘텐츠 박스를 “그리드”라고도 불렀습니다. 이번 강의의 그리드는 `display: grid` 속성을 사용하는 CSS Grid와는 다른 맥락입니다.

### 실습 9. 높이의 중복 지정 정리

처음에는 부모와 자식 모두 높이를 지정하는 모습을 비교했습니다.

```css
.utility-menu {
  height: 35px;
  border: 1px solid red;
}

.con {
  width: 1050px;
  height: 35px;
  border: 1px solid orange;
}
```

강사님은 물풍선을 비유로 설명했습니다. 일반 문서 흐름에서 자식이 공간을 차지하면 부모는 보통 그 자식의 높이를 포함합니다.

이제 **부모 `.utility-menu`의 `height: 35px;`를 삭제**하고 자식 `.con`에만 남깁니다.

```css
.utility-menu {
  border: 1px solid red;
}

.con {
  width: 1050px;
  height: 35px;
  border: 1px solid orange;
}
```

> 강사님 강조: 높이를 불필요하게 중복 지정하지 말고 꼭 필요한 위치에 지정하세요.

### 실습 11. `nav`, `ul`, `li` 메뉴 구조

| 태그 | 읽는 방법 | 역할 |
|---|---|---|
| `nav` | 내브 | 내비게이션 영역 |
| `ul` | 유엘 | 순서 없는 목록 |
| `li` | 엘아이 | 목록의 개별 항목 |

1. `index.html`에서 `.con`의 여는 태그와 닫는 태그 사이에 커서를 놓습니다.
2. `nav`를 입력하고 `Tab`을 누릅니다.
3. `nav` 안에 `ul`을 입력하고 `Tab`을 누릅니다.
4. `ul` 안에 `li*3`을 입력하고 `Tab`을 누릅니다.
5. 각 `li`에 `회원가입`, `로그인`, `고객센터`를 입력합니다.

```html
<nav>
  <ul>
    <li>회원가입</li>
    <li>로그인</li>
    <li>고객센터</li>
  </ul>
</nav>
```

**Emmet 추가 연습:**

```text
nav>ul>li*3
```

- `>` : 자식 요소 만들기
- `*3` : 요소 세 번 반복
- `Tab` : Emmet 확장

**개념 바로잡기:** 강의에서는 영수증 제목과 리스트를 비유로 설명했지만, `ul` 자체는 제목 태그가 아니라 **목록 전체를 감싸는 요소**입니다. 제목이 필요하면 별도의 제목 요소를 사용합니다.

### 실습 12. 목록 기본 스타일 없애기

`style.css`의 `body` 규칙 아래에 작성합니다.

```css
ul,
li {
  margin: 0;
  padding: 0;
  list-style: none;
}
```

- `margin` : 바깥 여백
- `padding` : 안쪽 여백
- `list-style: none` : 목록 기호 제거
- `ul, li` : 두 선택자를 쉼표로 구분해 함께 선택

강의에서는 기본 스타일을 정리하는 작업을 Normalize라고 설명했습니다. 엄밀하게는 Normalize와 Reset을 구분하기도 하며, 위 예제는 **목록 부분의 기본 스타일 초기화**입니다.

### 실습 13. 메뉴 세 개를 가로로 정렬하기

`li` 세 개를 가로 배치하려면 그 부모인 `ul`에 `display: flex`를 작성합니다.

`style.css`에서 `.con` 아래에 새 선택자를 추가합니다.

```css
.con > nav > ul {
  display: flex;
  gap: 12px;
}
```

`.con > nav > ul`은 `.con`의 직접 자식 `nav` 안에 있는 직접 자식 `ul`을 선택합니다.

`gap: 12px`은 Flex 항목 사이 간격을 12px로 만듭니다.

**직접 실험:**

1. `gap: 0;`으로 바꾸고 메뉴 간격을 관찰합니다.
2. `gap: 12px;`로 바꾸고 비교합니다.
3. `gap: 30px;`로 바꾸고 비교합니다.
4. 최종적으로 수업 값인 `12px`로 복구합니다.

## ⑤ 코드 한 줄씩 핵심 문법 해설

| 기호 | 사용 위치 | 뜻 |
|---|---|---|
| `< >` | HTML | 태그의 꺾쇠괄호 |
| `.` | CSS 선택자 | 클래스 선택 |
| `#` | CSS 선택자 | ID 선택 |
| `#` | CSS 색상값 | 16진수 색상 |
| `{ }` | CSS | 선언 블록 |
| `:` | CSS | 속성과 값 구분 |
| `;` | CSS | 선언 종료 |
| `,` | CSS | 선택자 또는 값의 항목 구분 |
| `>` | CSS 선택자 | 직접 자식 선택 |
| `*` | Emmet | 반복 생성 |

다음 코드를 분해해 봅니다.

```css
.con > nav > ul {
  display: flex;
  gap: 12px;
}
```

- `.con > nav > ul` : **선택자** — CSS가 적용될 요소를 지정
- `display` : 속성
- `flex` : 속성값
- `gap` : 속성
- `12px` : 속성값(픽셀 단위)
- `{ ... }` : 적용할 선언을 감싸는 부분

## ⑦ 오류 해결

| 오류 증상 | 확인 위치와 해결 방법 |
|---|---|
| Emmet의 `Tab`이 작동하지 않음 | HTML 모드 확인 → F1 → `Emmet: Expand Abbreviation` |
| HTML 태그가 화면에 글자로 보임 | `<`, `>`, 따옴표, 태그 닫힘 여부 확인 |
| CSS가 적용되지 않음 | HTML `class`와 CSS 선택자 철자가 같은지 확인 |
| 빨간 테두리가 보이지 않음 | `border: 1px solid red;` 오타·세미콜론 확인 |
| 타이핑할 때 기존 글자가 지워짐 | `Insert` 키로 덮어쓰기 모드 해제 |
| 메뉴가 세로로 보임 | `ul`의 `display: flex;` 확인 |
| 모든 메뉴가 보라색이 됨 | `.signup`이 첫 번째 `li`에만 있는지 확인 |
| 중앙 정렬이 안 됨 | `.con` 너비, `margin-left/right: auto`, 부모 너비 확인 |

### 강의 실제 오류 — HTML 태그 속성 쓰기

잘못된 코드:

```html
<div.class="utility-menu">
```

올바른 코드:

```html
<div class="utility-menu">
```

CSS에서 클래스를 고를 때는 점을 사용합니다.

```css
.utility-menu {
  border: 1px solid red;
}
```

### 초보자를 위한 추가 설명 — 좁은 화면의 너비 문제

기본 박스 모델에서 `width: 1050px`과 좌우 테두리 `1px`을 함께 쓰면 바깥 너비가 1052px일 수 있습니다. 좁은 화면에서는 가로로 넘칠 수 있습니다. 반응형 연습을 할 때는 다음 코드를 응용할 수 있습니다.

```css
.con {
  width: 100%;
  max-width: 1050px;
  box-sizing: border-box;
  margin-left: auto;
  margin-right: auto;
}
```

이는 강의 원문을 그대로 옮긴 코드가 아니라 **추가 응용**입니다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>마켓컬리 와이어프레임</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <!-- 상단 배너 -->
  <div class="top-banner">
    지금 가입하고 최대 12,000원 할인 받아가세요!
  </div>

  <!-- 유틸리티 메뉴 -->
  <div class="utility-menu">
    <div class="con">
      <nav aria-label="회원 메뉴">
        <ul>
          <li class="signup">회원가입</li>
          <li>로그인</li>
          <li>고객센터</li>
        </ul>
      </nav>
    </div>
  </div>

</body>
</html>
```

**추가 설명:** `aria-label="회원 메뉴"`는 내비게이션 영역의 목적을 보조 기술에 전달하는 접근성 속성입니다. 실제로 이동하는 메뉴라면 `li` 안에 `a` 링크를 두는 것이 적절합니다. 이번 수업에서는 링크 작성까지 진행하지 않았으므로 텍스트만 사용합니다.

### 전체 완성 CSS (`style.css`)

```css
/* Pretendard 웹폰트 연결 */
@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css");

/* 전체 글꼴 */
body {
  margin: 0;
  font-family: "Pretendard", sans-serif;
}

/* 목록 기본 스타일 초기화 */
ul,
li {
  margin: 0;
  padding: 0;
  list-style: none;
}

/* 상단 배너 */
.top-banner {
  background-color: #5f0080;
  color: #fff;

  height: 42px;
  display: flex;
  justify-content: center;
  align-items: center;

  font-size: 14px;
}

/* 유틸리티 메뉴 */
.utility-menu {
  /* border: 1px solid red; */
}

/* 중앙 컨테이너 */
.con {
  width: 1050px;
  height: 35px;

  margin-left: auto;
  margin-right: auto;

  display: flex;
  justify-content: flex-end;
  align-items: center;

  /* border: 1px solid orange; */
}

/* 메뉴 목록 */
.con > nav > ul {
  display: flex;
  gap: 12px;

  font-size: 12px;
  color: #333;
}

/* 회원가입 메뉴 */
.signup {
  color: #5f0080;
}
```

### 전체 코드에 대한 정확성 안내

- 배너 높이 `42px`, 메뉴 글자 `12px`, 색상 `#333`, `#5f0080` 등은 학습용 재현에 사용한 **예시값**입니다.
- `body { margin: 0; }`은 브라우저 기본 여백을 제거하는 **추가 설정**입니다.
- 빨간색·주황색 테두리는 확인용이므로 완성 예시에서 주석 처리했습니다.
- 웹폰트 연결 코드는 강의에서 복사한 정확한 원문이 아니라 다른 공개 연결 방식의 예시입니다.

### 수업에서 안내한 시험·과제

강사님은 시험 준비 일정 때문에 다소 빠르게 수업을 진행했다고 설명했습니다. 평가에서는 외형적 완성도뿐만 아니라 **웹 표준과 접근성을 왜 고려했는지**도 중요하게 본다고 안내했습니다.

강의 당시 안내에 따르면 시험에서 AI 웹앱 사용은 허용하되 코딩 에이전트와는 구분했습니다. 실제 시험에는 최종 공지를 따르세요.

과제는 다음과 같습니다.

- 오늘 만든 화면을 다시 구현하며 복습하기
- 블로그나 메모에 학습 내용 정리하기
- 완성 코드 또는 미리보기 화면 캡처하기
- 강사님이 지정한 제출 위치에 결과물과 복습 분량 제출하기

### 꼭 기억할 개념

1. **Flexbox는 움직이려는 대상의 부모에 적용한다.**  
   `display: flex;`, `justify-content`, `align-items`
2. **너비가 정해진 블록은 양쪽 `auto` 마진으로 가운데 정렬할 수 있다.**  
   `margin-left: auto;`, `margin-right: auto;`
3. **메뉴는 `nav > ul > li` 구조로 만든다.**
4. **Flex 항목 사이 간격은 `gap`으로 설정한다.**  
   `gap: 12px;`
5. **특정 메뉴만 꾸미려면 `class`를 사용한다.**  
   HTML `class="signup"` ↔ CSS `.signup`

6. 같은 위치에 `아이콘` 폴더를 만듭니다.

```text
와이어프레임/
├─ 이미지/
│  ├─ 로고/
│  └─ 아이콘/
├─ index.html    ← 학습용 예시 파일명
└─ style.css     ← 학습용 예시 파일명
```

강사님은 한글 폴더명을 사용했으며 한글 폴더명도 사용할 수 있습니다. **초보자를 위한 추가 설명:** 실무에서는 `images`, `logo`, `icons` 등 영문 경로를 쓰기도 합니다.

## 7. 실습 ③ 개발자 도구로 로고 찾기

개발자 도구는 웹페이지의 HTML, CSS, 이미지 구조를 확인하는 기능입니다.

1. 마켓컬리 페이지를 엽니다.
2. `F12` 또는 `Ctrl + Shift + I`를 누릅니다.
3. `Elements`(요소) 탭을 찾습니다.
4. `Ctrl + Shift + C` 또는 요소 선택 아이콘을 클릭합니다.
5. 페이지에서 로고를 클릭합니다.
6. 선택된 요소와 상위(부모) 요소를 확인합니다.
7. 필요한 클래스명 등을 더블 클릭해 `Ctrl + C`로 복사합니다.

부모·자식 관계의 **설명용 예시**:

```html
<a class="logo-link" href="/">
  <img src="logo.svg" alt="컬리 로고">
</a>
```

- `<a>`: 링크 태그
- `<img>`: 이미지 태그
- `src`: 이미지 주소/경로
- `alt`: 대체 텍스트
- `class`: 요소를 분류·선택할 때 사용하는 속성

사이트의 실제 클래스명은 바뀔 수 있습니다. 위 HTML이 실제 마켓컬리 소스 그대로라는 뜻은 아닙니다.

### SVG란?

SVG(Scalable Vector Graphics)는 선과 도형을 코드로 표현하는 벡터 이미지 형식입니다. 확대해도 선명하게 표현할 수 있습니다.

수동 저장 절차:

1. 브라우저 개발자 도구에서 `<svg>` 요소를 찾습니다.
2. 해당 요소를 우클릭 → `Copy` → `Copy element`.
3. VS Code에서 `logo.svg` 같은 `.svg` 파일을 만듭니다.
4. 전체 SVG 요소를 붙여 넣고 저장합니다.
5. 이미지를 열어 정상 출력되는지 확인합니다.

`<path>`만 복사하면 필요한 `<svg>` 속성이나 구조가 빠질 수 있습니다.

> 공개 배포 시에는 원본 로고·아이콘의 상표권, 저작권, 사용 조건 등을 확인해야 합니다.

## 10. 실습 ⑥ 메인 헤더 HTML 만들기

### 10-1. 커서 위치 찾기

1. VS Code에서 기존 HTML 파일을 엽니다.
2. `Ctrl + B`를 눌러 왼쪽 사이드바를 숨기거나 표시합니다.
3. 탑 배너와 유틸리티 메뉴를 찾습니다.
4. 왼쪽 접기 화살표를 클릭해 긴 요소를 접습니다.
5. **유틸리티 메뉴의 마지막 닫는 태그 바깥쪽 다음 줄**로 이동합니다.
6. `Enter`로 새로운 줄을 만듭니다.

### 10-2. Emmet으로 박스 생성

HTML 파일에서 입력:

```text
div.main-header
```

`Tab`을 누르면:

```html
<div class="main-header"></div>
```

`div`는 상자 역할을 하는 HTML 요소이고, Emmet 문법의 `.`은 클래스 이름을 뜻합니다. 완성된 HTML의 클래스명 앞에는 점이 들어가지 않습니다.

### 10-3. CSS 배경 설정

CSS 파일의 맨 아래로 이동합니다. **기본 VS Code에서 문서 끝으로 가는 단축키는 `Ctrl + End`**입니다.

```css
.main-header {
  background-color: gray;
}
```

- `.main-header`: CSS 클래스 선택자
- `{`, `}`: 선언 블록 시작과 끝
- `background-color`: 배경색 속성
- `:`: 속성과 값 구분
- `gray`: 회색 값
- `;`: 선언 끝

`Ctrl + S`로 저장합니다. 자식 콘텐츠가 없는 빈 `div`는 높이가 0일 수 있어 배경색이 화면에서 보이지 않을 수 있습니다.

## 11. 핵심 개념 — 웹 그리드와 컴포넌트

유틸리티 메뉴와 메인 헤더는 **너비는 같아도 높이와 내부 정렬은 달라질 수 있습니다**.

```text
유틸리티 메뉴  ├──────────────────────┤  높이 A

메인 헤더      ├──────────────────────┤
               │                      │  높이 B
               └──────────────────────┘
               ↑ 공통 너비 ↑
```

공통 속성을 복사해서 중복 작성하기보다는 별도의 클래스로 추출하여 재사용할 수 있습니다.

**컴포넌트(Component)**는 재사용 가능한 UI 구성 단위를 말합니다. 다만 공통 CSS 클래스 **자체가 언제나 하나의 컴포넌트인 것은 아닙니다**. 컴포넌트에는 HTML 구조와 CSS, 필요에 따라 동작까지 포함될 수 있습니다.

## 12. 실습 ⑦ `.con` CSS 분리하기

### 분리 전 — 설명용 예시

> 아래 `1050px`, `40px`, 테두리 색은 강의 측정값이 아닌 예시입니다.

```css
.con {
  width: 1050px;
  height: 40px;
  margin: 0 auto;
  display: flex;
  justify-content: flex-end;
  align-items: center;
  border: 1px solid red;
}
```

### 공통/개별 속성 구분

| 속성 | 위치 | 이유 |
|---|---|---|
| `width` | `.con` | 공통 너비 |
| `margin: 0 auto` | `.con` | 공통 가로 중앙 정렬 |
| `display: flex` | `.con` | 공통 Flex 사용 |
| `border` | `.con` | 강의에서 공통 적용 |
| `height` | `.utility-con` | 영역마다 높이가 다름 |
| `justify-content: flex-end` | `.utility-con` | 유틸리티 메뉴 전용 |
| `align-items: center` | `.utility-con` | 강의에서 개별 클래스로 분리 |

### 분리 후 — 설명용 예시

```css
/* 컴포넌트 영역 */
.con {
  width: 1050px;
  margin: 0 auto;
  display: flex;
  border: 1px solid red;
}

/* 유틸리티 메뉴 전용 */
.utility-con {
  height: 40px;
  justify-content: flex-end;
  align-items: center;
}
```

### VS Code 수정 순서

1. CSS 파일에서 `Ctrl + F`로 `.con`을 찾습니다.
2. 기존 블록에서 `height` 선언을 잘라냅니다.
3. `justify-content`와 `align-items` 선언도 잘라냅니다.
4. `.utility-con { }`을 새로 만들어 세 선언을 넣습니다.
5. 공통 `.con` 블록을 선택하고 `Ctrl + X`로 잘라냅니다.
6. Normalize 영역 아래에 `/* 컴포넌트 영역 */` 주석을 만듭니다.
7. 그 아래 공통 `.con`을 붙여 넣습니다.
8. `Ctrl + S`로 저장합니다.

**코드 변경 전/후 비교:** 변경 전에는 모든 `.con`이 같은 높이·정렬을 받지만, 변경 후에는 `.utility-con`을 함께 사용하는 요소에만 유틸리티 전용 높이·정렬을 줄 수 있습니다.

## 13. 실습 ⑧ HTML에 클래스 두 개 적용하기

CSS 분리 직후 유틸리티 영역의 레이아웃이 달라질 수 있습니다. HTML에 `.utility-con`을 추가해야 합니다.

수정 전:

```html
<div class="con">
  <!-- 기존 유틸리티 메뉴 내용 -->
</div>
```

수정 후:

```html
<div class="con utility-con">
  <!-- 기존 유틸리티 메뉴 내용 -->
</div>
```

- `class`는 HTML 클래스 속성입니다.
- 두 클래스명은 **공백으로 구분**합니다.
- HTML의 `class` 값에 점을 쓰지 않습니다.
- CSS 선택자에서는 `.con`, `.utility-con`처럼 점을 씁니다.

### 직접 입력 문제

다음 물음표를 바꾸어 올바른 클래스 두 개를 입력하세요.

```html
<div class="?">유틸리티 메뉴</div>
```

<details>
<summary>정답과 해설 보기</summary>

```html
<div class="con utility-con">유틸리티 메뉴</div>
```

`con`과 `utility-con` 사이를 공백으로 나눕니다. `con.utility-con`은 두 클래스가 아닙니다.
</details>

## 14. 실습 ⑨ 메인 헤더의 내부 `.con` 만들기

1. HTML 파일에서 `.main-header`를 찾습니다.
2. 그 **여는 태그와 닫는 태그 사이**에 커서를 놓습니다.
3. `.con`을 입력하고 `Tab`을 누릅니다.
4. 아래처럼 부모·자식 관계가 되었는지 확인합니다.

```html
<div class="main-header">

</div>
```

`.main-header`가 부모이고 `.con`이 자식입니다. `.con`은 앞서 작성한 공통 컨테이너 스타일을 재사용합니다.

## 15. 실습 ⑩ 내부 박스 3개 만들기

화면에 로고, 검색, 아이콘 등 요소가 여러 개 있어도 먼저 **왼쪽·가운데·오른쪽의 3개 큰 영역**으로 나눕니다.

```text
.main-header
└─ .con
   ├─ div : 왼쪽(로고·브랜드)
   ├─ div : 가운데(검색)
   └─ div : 오른쪽(아이콘)
```

클래스 없이 생성하는 Emmet:

```text
div*3
```

`Tab`을 누른 결과:

```html
<div></div>
<div></div>
<div></div>
```

클래스를 바로 지정하는 추가 예시:

```text
div.box*3
```

결과:

```html
<div class="box"></div>
<div class="box"></div>
<div class="box"></div>
```

> 강의에서는 박스 3개를 먼저 생성한 뒤 클래스와 스타일을 지정하겠다고 설명했습니다.

### Emmet 입력 연습

1. `div` 세 개를 만드는 문법은?
2. `box` 클래스가 붙은 `div` 하나를 만드는 문법은?
3. `.con` 부모 안에 `.box` 자식 3개를 만드는 문법은?

<details>
<summary>정답과 해설 보기</summary>

1. `div*3` — `*3`은 반복 횟수입니다.
2. `.box` 또는 `div.box` — 점 뒤는 클래스 이름입니다.
3. `.con>.box*3` — `>`는 부모·자식 관계입니다.
</details>

**Emmet 작동하지 않을 때:** HTML 언어 모드인지, 커서가 속성값/주석 안에 있는지 확인합니다. `Ctrl + Shift + P` → `Emmet: Expand Abbreviation`을 실행할 수도 있습니다.

## 16. 초보자를 위한 추가 설명 — Flexbox CSS 값 실험

강의에서 앞서 배운 `display: flex`를 다시 사용했습니다. 아래 추가 연습으로 값의 차이를 VS Code에서 직접 확인합니다.

```css
.con {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 8px;
}
```

| 속성 | 역할 | 변경해 볼 값 |
|---|---|---|
| `flex-direction` | 주축 방향 | `row`, `column` |
| `justify-content` | 주축 정렬 | `flex-start`, `center`, `flex-end`, `space-between`, `space-around` |
| `align-items` | 교차축 정렬 | `flex-start`, `center`, `flex-end` |
| `gap` | 아이템 사이 간격 | `0px`, `8px`, `16px`, `32px` |
| `background-color` | 배경색 | `#EDE3F2`, `#D9EAFB`, `#D9F1E4` |

### 실습

1. 아래의 최종 예시 프로젝트를 실행합니다.
2. `.main-header .con`의 `justify-content`를 `center`로 바꾸고 저장합니다.
3. 브라우저에서 세 박스가 어떻게 이동하는지 확인합니다.
4. `gap`을 `32px`로 변경해 박스 간격을 비교합니다.
5. `flex-direction: column;`을 넣어 세로 배치를 확인합니다.
6. 다시 `row`와 `space-between`으로 되돌립니다.

**주의:** 원래 채팅창의 슬라이더 미리보기는 Markdown 파일에 보존되지 않습니다. 위 단계는 실제 브라우저에서 결과를 확인하도록 바꾼 연습입니다.

## ③ 핵심 개념 설명

### 1. `display: flex`와 `justify-content: space-between`

- **읽기:** 디스플레이 플렉스 / 저스티파이 콘텐츠 스페이스 비트윈
- **역할:** 부모 안의 자식들을 Flex 방식으로 배치하고, 기본 가로 방향에서 첫 요소를 왼쪽 끝, 마지막 요소를 오른쪽 끝에 배치합니다.
- **구별하기:** `display: flex`는 배치 방식을 설정하고 `justify-content`는 **주축** 정렬 방식을 정합니다. `flex-direction: row`에서 주축은 가로입니다.

```css
.m-header-con {
  display: flex;
  justify-content: space-between;
}
```

> **강사님 강조:** 수업에서는 `space-around`가 아니라 `space-between`을 사용했습니다. 다만 `space-around`가 잘못된 CSS인 것은 아니며 목적에 따라 사용할 수 있습니다.

### 2. `padding` — 안쪽 여백

- **읽기:** 패딩
- **역할:** 요소의 콘텐츠와 테두리 사이의 안쪽 여백
- **비교:** `margin`은 바깥 여백입니다.

```text
요소 바깥쪽: margin
┌────────── 테두리 ───────────┐
│          padding           │
│      ┌────────────┐        │
│      │  콘텐츠    │        │
│      └────────────┘        │
└────────────────────────────┘
```

| 속성 | 의미 |
|---|---|
| `padding-top` | 안쪽 위 여백 |
| `padding-bottom` | 안쪽 아래 여백 |
| `padding-left` | 안쪽 왼쪽 여백 |
| `padding-right` | 안쪽 오른쪽 여백 |
| `margin` | 요소 바깥 여백 |

강의에서는 상하에 각각 `12px`을 적용했습니다. 높이를 고정하지 않으면 콘텐츠 높이에 패딩이 더해져 높이가 자연스럽게 결정됩니다.

### 3. `align-items: center` — 교차축 중앙 정렬

- **읽기:** 얼라인 아이템즈 센터
- **역할:** Flex 부모의 자식들을 교차축 방향으로 정렬합니다.
- 기본 `flex-direction: row`에서 교차축은 세로입니다.

```css
.brand {
  display: flex;
  align-items: center;
}
```

**어느 부모에 작성하는지**가 핵심입니다.

| 선택자 | 정렬 대상 |
|---|---|
| `.m-header-con` | 큰 영역 3개 (`.brand`, `.search`, `.icon-box`) |
| `.brand` | 로고와 브랜드 탭 묶음 |
| `.brand-tabs` | 마켓컬리와 뷰티컬리 탭 |

### 4. `gap` — 자식 요소 사이 간격

```css
.brand {
  display: flex;
  gap: 20px;
}

.brand-tabs {
  display: flex;
  gap: 22px;
}
```

첫 번째 `gap`은 **로고와 브랜드 탭 묶음 사이**, 두 번째 `gap`은 **두 브랜드 탭 사이**를 뜻합니다.

### 5. 두 클래스를 동시에 선택하기

HTML:

```html
<div class="brand-tab active">마켓컬리</div>
<div class="brand-tab">뷰티컬리</div>
```

CSS:

```css
.brand-tab.active {
  color: #5F0080;
  font-weight: 500;
}
```

| 선택자 | 의미 |
|---|---|
| `.brand-tab` | brand-tab 클래스를 가진 모든 요소 |
| `.active` | active 클래스를 가진 모든 요소 |
| `.brand-tab.active` | **같은 요소**가 두 클래스를 모두 가진 경우 |
| `.brand-tab .active` | brand-tab 요소 **안쪽 자손** 중 active 클래스를 가진 경우 |

`#5F0080`은 이 문서의 **실습용 보라색 예시**입니다.

### 6. `box-sizing: border-box` — 너비 계산

기본 `content-box` 상태에서는 지정한 `width`에 패딩과 테두리가 더해집니다.

예를 들어 `width: 400px`, 좌우 `padding: 20px`, 양쪽 테두리 각각 `1px`이라면:

```text
content-box : 400 + 20 + 20 + 1 + 1 = 442px
border-box  : 전체 너비가 400px
```

```css
.search {
  width: 400px;
  padding-left: 20px;
  padding-right: 20px;
  box-sizing: border-box;
}
```

이 속성은 검색창 크기가 의도치 않게 늘어나는 문제를 해결합니다.

강의에서는 `.con`에 이미 Flex가 적용되어 있다고 설명했습니다. 실제 프로젝트의 기존 구조를 확인해 중복 선언을 줄일 수 있습니다.

**기호 읽기:** `.`은 클래스 선택자 앞에 붙고, `{ }`는 CSS 선언 범위를 나타냅니다. `:`는 속성과 값의 구분, `;`는 선언의 끝입니다.

### STEP 2. 박스 3개에 클래스 이름 지정

`index.html`의 기존 메인 헤더 안에서 3개 박스를 찾으세요. 기존 박스가 있다면 새로 추가하지 않고 `class`를 수정합니다.

```html
<div class="m-header-con">
  <div class="brand">브랜드</div>
  <div class="search">검색창</div>
  <div class="icon-box">아이콘</div>
</div>
```

**Emmet 연습 (빈 HTML 연습 파일에서만):**

1. HTML의 `<body>` 안에 커서를 놓습니다.
2. `.m-header-con>.brand+.search+.icon-box`를 입력합니다.
3. `Tab`을 눌러 확장합니다.

```html
<div class="m-header-con">
  <div class="brand"></div>
  <div class="search"></div>
  <div class="icon-box"></div>
</div>
```

`>`는 자식 관계, `+`는 형제 관계입니다. `Tab` 확장이 안 되면 VS Code의 Emmet 설정 또는 제안 목록을 확인하고, 직접 HTML 태그를 입력해도 됩니다.

### STEP 3. 상하 패딩 적용

**파일:** `style.css` → `.m-header-con`의 중괄호 안

```css
  justify-content: space-between;
  padding-top: 12px;
```

저장(`Ctrl + S`)한 후 브라우저에서 박스 위아래 여백을 확인하세요.

### STEP 4. 로고 이미지 삽입

**파일:** `index.html` → `.brand` 내부

1. 임시 텍스트 `브랜드`를 지웁니다.
2. 빈 공간에 `img`를 입력하고 `Tab`을 누릅니다.
3. 생성된 `src`, `alt` 속성을 작성합니다.

```html
<div class="brand">
  <img src="./images/logo.svg" alt="마켓컬리 로고">
</div>
```

**`src`**는 파일 경로이고 **`alt`**는 이미지의 대체 텍스트입니다. 이미지가 안 보일 때뿐 아니라 접근성을 위해서도 의미 있습니다.

| 경로 | 뜻 |
|---|---|
| `./images/logo.svg` | 현재 HTML 파일 위치의 images 폴더 |
| `../images/logo.svg` | 한 단계 상위 폴더의 images 폴더 |
| `/images/logo.svg` | 웹사이트 루트 기준 images 경로 |

실제 경로는 자신의 파일 구조에 따라 수정합니다.

### STEP 5. 브랜드 탭 2개 추가

**파일:** `index.html` → `<img>` 바로 아래, `.brand` 안

`class="brand-tab active"`는 클래스를 **두 개** 지정한 것입니다. `active`는 선택된 탭을 표현합니다.

### STEP 6. 로고와 탭 정렬

```css
.m-header-con {
```

### STEP 9. 활성화 탭 스타일

**파일:** `style.css`


### STEP 10. 검색창 가운데 배치

좌우 영역의 크기가 다르면 `space-between`을 적용해도 가운데 박스가 전체 화면의 정확한 중앙에서 벗어날 수 있습니다. 강의에서는 좌우 영역을 각각 `250px`로 맞췄습니다.

```css
.brand {
  display: flex;
  align-items: center;
  gap: 20px;
  width: 250px;
}

.icon-box {
  width: 250px;
  display: flex;
  justify-content: flex-end;
}
```

`justify-content: flex-end`는 오른쪽 끝으로 보내기 위한 이 문서의 학습용 구현입니다.

### STEP 11. 검색창 크기 지정

### STEP 12. 둥근 모서리

처음 `12px`로 설정했다가 `8px`로 수정했습니다.

```css
.search {
  width: 400px;
  height: 48px;
  border: 1px solid #5F0080;
  border-radius: 8px;
}
```

### STEP 13. 좌우 패딩과 `box-sizing`

```css
.search {
  width: 400px;
  height: 48px;
  border: 1px solid #5F0080;
  border-radius: 8px;
  padding-left: 20px;
  padding-right: 20px;
  box-sizing: border-box;
}
```

`box-sizing: border-box`를 사용하면 패딩과 테두리가 400px 너비 안에 들어갑니다.

### STEP 14. 검색창 글자 중앙 정렬

**파일:** `style.css`

```css
.search {

  height: 48px;

  border-radius: 8px;
  padding-left: 20px;
  padding-right: 20px;

  align-items: center;
```


## ⑦ 오류 해결

### 오류 1. 세로 중앙 정렬이 안 됨

**원인:** 원하는 자식의 바로 위 Flex 부모가 아닌 다른 요소에 정렬 속성을 적용했을 수 있습니다.

1. 브라우저에서 `F12`를 누릅니다.
2. 요소 선택 도구로 어긋난 박스를 선택합니다.
3. 해당 요소를 감싸는 부모가 `.brand`인지 확인합니다.
4. `.brand`에 `display: flex`와 `align-items: center`가 모두 있는지 확인합니다.

### 오류 2. 활성 탭에 색이 적용되지 않음

```css
/* 잘못된 예: HTML의 클래스는 brand-tab */
.brand-tabs.active { color: #5F0080; }

/* 올바른 예 */
.brand-tab.active { color: #5F0080; }
```

HTML과 CSS의 `tab` / `tabs` 철자를 비교하세요.

### 오류 3. 너비와 높이가 적용되지 않음

```css
/* 잘못된 예 */
.search { width: 400; height: 48; }

/* 올바른 예 */
.search { width: 400px; height: 48px; }
```

길이값에는 `px` 같은 적절한 단위가 필요합니다.

### 오류 4. 패딩 때문에 검색창이 커짐

```css
.search {
  width: 400px;
  padding-left: 20px;
  padding-right: 20px;
  box-sizing: border-box;
}
```

### 오류 5. 로고가 표시되지 않음

- 이미지 파일명과 확장자를 정확히 확인합니다.
- 실제 HTML 파일의 폴더 위치를 확인합니다.
- `./`와 `../` 사용이 맞는지 확인합니다.
- 브라우저 개발자 도구의 오류 메시지를 확인합니다.

## ④ Emmet으로 아이콘 박스 3개 생성하기

### 1. 이번에 사용하는 Emmet

강사님은 `ac-icon`이라는 공통 클래스를 만들고, 각 박스를 구별할 숫자가 붙은 두 번째 클래스를 추가했습니다.

**입력 연습:** 다음 조건에 맞는 Emmet 문법을 먼저 직접 작성해 보세요.

- 공통 클래스: `ac-icon`
- 개별 클래스: `aci01`, `aci02`, `aci03`
- 생성할 요소: `div` 세 개

**정답**

```text
.ac-icon.aci0$*3
```

### 2. 직접 입력할 코드

HTML 파일의 `action` 부모 요소 안쪽 빈 줄에 커서를 놓고 다음을 입력합니다.

```text
.ac-icon.aci0$*3
```

`Tab`을 눌러 확장하면 다음과 같이 생성됩니다.

```html
<div class="ac-icon aci01"></div>
<div class="ac-icon aci02"></div>
<div class="ac-icon aci03"></div>
```

| 문법 | 의미 |
|---|---|
| `.` | 클래스 지정 |
| `ac-icon` | 세 박스에 공통으로 적용할 클래스 |
| `.aci0$` | 번호가 붙는 개별 클래스 |
| `$` | 1, 2, 3으로 증가하는 숫자 |
| `*3` | 같은 구조를 세 번 생성 |

### 3. 클래스가 두 개인 이유

```text
부모: action
 ├─ ac-icon aci01
 ├─ ac-icon aci02
 └─ ac-icon aci03
```

공통 클래스는 세 박스를 한꺼번에 꾸밀 때 사용하고, 개별 클래스는 특정 박스만 꾸밀 때 사용합니다.

### 4. Codex로 클래스 이름 수정하기

강사님은 임시로 작성한 클래스 이름을 AI 에이전트에게 더 적절한 이름으로 수정하도록 요청했습니다. HTML뿐 아니라 연결된 CSS의 선택자도 함께 변경하라고 할 수 있다고 설명했습니다.

**초보자를 위한 추가 설명 — Codex 요청 예시**

> 현재 HTML에서 오른쪽 아이콘 세 개에 사용한 클래스 이름을 역할에 맞게 짧고 알아보기 쉽게 수정해 줘. 기존 HTML 구조는 유지하고, 연결된 CSS 선택자도 함께 변경해 줘. 변경 전후 이름과 수정한 파일을 간단하게 알려줘.

이후 예제에서는 이해를 돕기 위해 별도의 이름을 사용합니다.

강사님은 Codex의 권한을 Full Access로 변경하는 모습도 보여주었습니다. 그러나 Full Access는 파일 수정이나 명령 실행 범위를 넓힐 수 있습니다. 초보자는 필요한 권한만 허용하고, AI가 변경한 파일과 내용을 검토하는 것이 안전합니다.

## ⑤ Google Material Symbols 아이콘 가져오기

### 1. Google Material Symbols란?

Google Material Symbols는 웹사이트에 위치, 검색, 장바구니 같은 아이콘을 표시할 수 있도록 제공하는 아이콘 모음입니다.

이번 수업에서는 마켓컬리 오른쪽 아이콘을 기존 이미지 대신 Material Symbols로 구현했습니다.

| 용도 | 아이콘 이름 예시 | 수업에서 확인 여부 |
|---|---|---|
| 위치 | `location_on` | |
| 찜 | `favorite` | 보충 실습 예시 |
| 장바구니 | `shopping_cart` | 보충 실습 예시 |

### 2. 아이콘 사이트에서 복사하기

1. Chrome 브라우저를 실행합니다.
2. 검색창에 `Google Material Symbols`를 입력합니다.
3. https://fonts.google.com/icons 페이지를 엽니다.
4. 검색창에서 `location_on`을 검색합니다.
5. 원하는 아이콘을 클릭합니다.
6. 오른쪽에 표시되는 아이콘 코드에서 `Copy code`를 선택합니다.
7. VS Code로 돌아와 첫 번째 아이콘 박스 안에 붙여 넣습니다.

아이콘을 표시하는 기본 HTML 구조는 다음과 같습니다.

```html
<span class="material-symbols-outlined">
  location_on
</span>
```

**코드 한 줄씩 해설**

- `<span>`: 문장이나 다른 요소 안에서 특정 부분을 묶는 HTML 태그입니다.
- `class="material-symbols-outlined"`: Google 아이콘 스타일을 적용할 클래스입니다.
- `location_on`: 표시할 아이콘의 이름입니다.
- `</span>`: span 요소가 끝났음을 표시합니다.

### 3. 아이콘 폰트 연결하기

강사님은 아이콘 코드만 붙여 넣는 것으로는 충분하지 않으며, 웹폰트를 불러오는 `link`가 필요하다고 설명했습니다.

HTML 파일의 `<head>` 영역에서 `<title>` 아래, 기존 CSS 연결 코드 위에 다음 코드를 추가할 수 있습니다.

```html
<!-- 구글 심볼 -->
<link
  href="https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined"
  rel="stylesheet"
>

<link rel="stylesheet" href="style.css">
```

**초보자를 위한 추가 설명:** 위 코드는 일반적인 연결 예시입니다. 강의에서 복사한 링크의 정확한 문자열은 영상 화면에서 확인해야 합니다.

강의에서는 복사한 링크에 `&icon_names=`와 같이 특정 아이콘 이름을 제한하는 부분이 있으면 제거해 여러 아이콘을 표시하도록 안내했습니다.

- `<head>`: 문서 설정과 외부 리소스 연결을 작성하는 영역.
- `<link>`: 외부 스타일시트를 HTML에 연결하는 태그.
- `href`: 가져올 리소스의 주소.
- `rel="stylesheet"`: 연결한 리소스가 CSS 스타일시트임을 뜻함.

외부 Google 아이콘 스타일을 기존 CSS보다 앞에 연결하면, 뒤에 작성한 CSS로 기본 스타일을 조정하기 편리합니다. 실제 적용 여부는 선택자 우선순위에도 영향을 받습니다.

## ⑥ 아이콘 사이 간격 설정하기

지난 4교시에서 배운 `display: flex`를 다시 사용합니다. 강사님은 검색창 높이가 약 `48px`이었다는 점을 참고해 간격을 예상해 보도록 했고 `40px`을 적용했습니다.

### VS Code 작업 순서

1. 기존 CSS 파일을 엽니다.
2. `Ctrl + End`를 눌러 파일 맨 아래로 이동합니다.
3. 기존 `.action` 선택자를 찾습니다.
4. `display: flex;`가 이미 있다면 유지합니다.
5. 아래에 `gap: 40px;`을 추가합니다.

```css
.action {
  display: flex;
  gap: 40px;
}
```

- `display: flex`: 자식 요소들을 기본적으로 가로로 배치.
- `gap: 40px`: 자식 요소 사이의 간격을 40픽셀로 설정.

### 직접 값 변경해 보기

다음 값 중 하나를 선택해 `gap`을 수정하고, Live Server 화면에서 차이를 관찰합니다.

| CSS | 예상 결과 |
|---|---|
| `gap: 0px;` | 아이콘 사이 여백이 없음 |
| `gap: 20px;` | 아이콘 사이가 20px 벌어짐 |
| `gap: 40px;` | 수업에서 설정한 간격 |
| `gap: 80px;` | 아이콘 사이가 80px 벌어짐 |

> 채팅창에서 제공했던 슬라이더와 미리보기는 일반 `.md` 파일에 저장하면 작동하지 않습니다. 위 연습은 VS Code와 브라우저에서 직접 실행하는 형태로 대체했습니다.

## ⑦ ID 선택자와 CSS 선택자 이해하기

이번 수업에서 특히 중요한 부분입니다. 강사님은 개발자 도구를 열어 Material Symbols에 기본 적용된 CSS를 확인하고, 아이콘 크기를 `28px`로 바꾸기 위해 선택자를 더 구체적으로 작성하는 방법을 설명했습니다.

### 1. `class`와 `id`의 차이

| 구분 | class | id |
|---|---|---|
| HTML 속성 | `class="action"` | `id="action"` |
| CSS 선택 | `.action` | `#action` |
| 중복 사용 | 여러 요소에 가능 | 한 문서에서 고유해야 함 |
| 주요 목적 | 여러 요소에 공통 스타일 | 특정 요소 식별 |
| 선택자 우선순위 | ID보다 낮음 | 클래스보다 높음 |

한 요소에 `class`와 `id`를 동시에 작성할 수도 있습니다.

```html
<div class="action" id="action">
  ...
</div>
```

**강사님 강조:** ID는 HTML 문서 안에서 같은 값을 반복하지 않습니다.

### 2. 자손 선택자와 쉼표

```css
#action .location,
#action .favorite,
#action .shopping {
  font-size: 28px;
}
```

`#action .location`에서 **공백 한 칸**은 `action` 요소 내부의 `location` 클래스를 가진 자손 요소를 선택한다는 뜻입니다.

강사님은 초보자가 이해하기 쉽도록 ‘아래에 있는 것을 선택한다’고 설명했습니다. 정확하게는 바로 아래 자식뿐 아니라 더 깊은 단계에 있는 자손도 선택합니다.

쉼표(`,`)는 여러 선택자를 묶어 같은 CSS 선언을 적용합니다. 따라서 위 코드는 세 종류의 아이콘에 모두 `font-size: 28px`을 적용합니다.

### 3. 왜 아이콘 크기가 바뀌지 않았을까?

강의에서는 처음에 부모 박스를 선택하여 `font-size: 28px`을 설정했지만 아이콘 크기가 바뀌지 않았습니다. Material Symbols 자체에 기본 `font-size`가 지정되어 있어 부모의 글자 크기 변경만으로는 자식 아이콘에 직접 지정된 크기를 덮어쓰지 못할 수 있습니다.

**초보자를 위한 추가 설명:** 아이콘의 `<span>` 요소를 직접 선택하면 됩니다.

```css
#action .material-symbols-outlined {
  font-size: 28px;
}
```

이 코드는 강의에서 작성한 세 개의 개별 선택자를 단순화한 보충 예시입니다. 실제 강의에서는 아이콘별 클래스를 사용해 쉼표로 선택자를 연결했습니다.

### 4. 개발자 도구로 확인하기

1. 브라우저에서 실습 페이지를 엽니다.
2. `F12`를 눌러 개발자 도구를 엽니다.
3. 왼쪽 위 요소 선택 아이콘을 클릭합니다.
4. 아이콘 하나를 클릭합니다.
5. `Styles` 영역에서 `font-size`를 확인합니다.
6. 기본 `24px`에 취소선이 나타나고 새로 지정한 `28px`이 적용되었는지 확인합니다.

취소선은 해당 CSS 선언이 현재 최종 스타일로 적용되지 않는다는 표시입니다.

## ⑧ 마우스를 올리면 색상이 바뀌게 만들기

강의에서는 아이콘에 마우스를 올렸을 때 손가락 모양의 커서가 나타나고 색상이 바뀌도록 만들었습니다.

### 1. `cursor: pointer`

```css
#action .ac-icon {
  cursor: pointer;
}
```

- `cursor`: 마우스 커서 모양을 설정하는 CSS 속성.
- `pointer`: 손가락 모양으로 표시하는 값.

`cursor: pointer`만으로 실제 클릭 기능이 생기는 것은 아닙니다. 동작을 구현하려면 링크나 버튼 등의 적절한 HTML 요소 또는 JavaScript가 필요합니다.

### 2. `:hover` 가상 클래스

`:hover`는 마우스 포인터가 해당 요소 위에 올라와 있는 상태를 선택합니다.

```css
#action .location:hover,
#action .favorite:hover,
#action .shopping:hover {
  color: purple;
}
```

### 3. 직접 실험하기

아래 색상값을 하나씩 바꾸어 저장한 뒤 브라우저에서 아이콘에 마우스를 올려 보세요.

| 색상 | 예시 값 |
|---|---|
| 보라색 | `#5f0080` |
| 빨간색 | `#e53935` |
| 파란색 | `#1976d2` |
| 초록색 | `#2e7d32` |

```css
#action .material-symbols-outlined:hover {
  color: #5f0080;
}
```

위 코드는 **추가 실습용 단순화 예시**입니다. 실제 수업에서는 세 아이콘의 개별 클래스를 각각 지정했습니다.

## ⑨ 수업 중 실제로 발생한 오류 해결

### 오류 1. 가운데 아이콘만 CSS가 적용됨

**강의 상황:** 가운데 아이콘은 크기가 바뀌지만 양쪽 아이콘은 변경되지 않는 문제가 발생했습니다. 강사님은 `id`를 잘못된 위치에 지정한 것을 발견하고, 세 아이콘의 공통 부모 요소로 이동하도록 안내했습니다.

**잘못된 구조의 예시**

```html
<div class="action">
  <div id="action" class="ac-icon">...</div>
  <div class="ac-icon">...</div>
  <div class="ac-icon">...</div>
</div>
```

**수정한 구조**

```html
<div class="action" id="action">
  <div class="ac-icon">...</div>
  <div class="ac-icon">...</div>
  <div class="ac-icon">...</div>
</div>
```

이제 `#action .ac-icon`은 세 아이콘 박스를 모두 선택할 수 있습니다.

### 오류 2. Hover 색상이 일부 아이콘에만 적용됨

강사님은 쉼표가 빠져 있는지 확인하라고 했습니다.

```css
/* 정상적인 선택자 연결 */
#action .location:hover,
#action .favorite:hover,
#action .shopping:hover {
  color: purple;
}
```

마지막 선택자 뒤에는 쉼표가 필요하지 않습니다. 중간 쉼표가 빠지면 선택자의 의미가 달라져 예상하지 못한 결과가 발생할 수 있습니다.

### 오류 3. 장바구니 아이콘만 크기가 다름

수업에서 HTML에는 `shopping`이라고 작성했지만 CSS에서는 `shopping_cart`를 선택한 사례가 있었습니다.

```html
<span class="shopping">shopping_cart</span>
```

```css
/* 잘못된 선택 */
.shopping_cart {
  font-size: 28px;
}

/* HTML 클래스와 일치하는 선택 */
.shopping {
  font-size: 28px;
}
```

`shopping_cart`라는 **아이콘 이름**과 `shopping`이라는 **CSS 클래스 이름**은 서로 다른 개념입니다.

**오류 해결 순서:** HTML 클래스 확인 → CSS 선택자 비교 → 공백·쉼표·점 확인 → 개발자 도구에서 적용 여부 확인.

강사님은 오류가 생겼을 때 정답 코드를 바로 복사하기보다 직접 원인을 찾고 수정하는 연습이 중요하다고 강조했습니다.

## ⑪ 복습 문제 — 직접 풀어보기

먼저 아래 문제를 풀고 정답·해설을 확인하세요.

**문제 1.** 클래스 이름이 `action`인 요소를 CSS에서 선택하려면?

- A. `#action`
- B. `.action`
- C. `action()`

**문제 2.** 세 개의 아이콘 사이에 40px 간격을 주는 CSS는?

- A. `padding: 40px;`
- B. `margin: 40px;`
- C. `gap: 40px;`

**문제 3.** 부모 `#action` 안에 있는 `.location`을 선택하는 코드는?

- A. `#action .location`
- B. `#action.location`
- C. `#action, .location`

**문제 4.** 마우스를 올렸을 때 색상을 바꾸는 가상 클래스는?

- A. `::before`
- B. `:hover`
- C. `:active-only`

**문제 5.** HTML 문서에서 고유하게 사용해야 하는 속성값은?

- A. `class`
- B. `id`
- C. `style`

### 정답 및 해설

| 문제 | 정답 | 해설 |
|---|---|---|
| 1 | **B** | 점(`.`)은 클래스 선택자이고 샵(`#`)은 ID 선택자입니다. |
| 2 | **C** | Flexbox에서 `gap`은 자식 요소 사이의 간격을 설정합니다. |
| 3 | **A** | 공백은 자손 선택자입니다. 붙여 쓰면 한 요소에 두 조건을 요구하고 쉼표는 별개 선택자를 묶습니다. |
| 4 | **B** | `:hover`는 마우스가 요소 위에 올라온 상태를 선택합니다. |
| 5 | **B** | `id` 값은 같은 HTML 문서 안에서 고유해야 합니다. |

**채점 방법:** 각 20점, 총 100점.

## ⑭ 오늘의 핵심 요약

**첫째, HTML 구조가 올바르게 작성되어야 CSS 선택자도 의도대로 작동합니다.** 특히 부모 요소의 위치, 클래스 이름, ID 위치를 확인해야 합니다.

3. 이미지가 부모 영역을 넘어서 가로 스크롤이 생기는 원인을 찾을 수 있다.
4. `object-fit: cover`를 사용해 이미지 비율을 유지할 수 있다.
5. `h2`, `p`로 상품 섹션의 제목과 설명을 작성할 수 있다.
6. `padding`, `text-align`으로 여백과 정렬을 조절할 수 있다.
7. `display: flex`, `flex-grow`, `flex-basis`, `gap`으로 카드 4개를 같은 너비로 배치할 수 있다.

## ③ 핵심 개념 설명

### 1. 시맨틱 HTML

시맨틱(Semantic)은 **의미가 있는**이라는 뜻입니다. HTML에서 각 영역이 어떤 역할을 하는지 알 수 있도록 의미에 맞는 태그를 사용합니다.

| 태그 | 읽는 방법 | 역할 |
|---|---|---|
| `<header>` | 헤더 | 페이지 또는 구역의 머리말 |
| `<main>` | 메인 | 페이지의 핵심 콘텐츠 |
| `<section>` | 섹션 | 주제별 콘텐츠를 묶는 구역 |
| `<div>` | 디브 | 별도의 의미가 없는 범용 묶음 |
| `<h2>` | 에이치 투 | 두 번째 수준의 제목 |
| `<p>` | 피 | 문단 |

이번에 만드는 구조의 개념도:

```text
body
├── header
│   ├── top-banner
│   ├── utility-menu
│   └── main-header
└── main
    ├── banner
    └── product
        └── con
            ├── product-header
            └── product-list
                ├── product-card
                ├── product-card
                ├── product-card
                └── product-card
```

**강사님 강조:** 웹디자인 관련 평가에서도 의미에 맞는 구조를 사용하는 것이 중요합니다.

**초보자를 위한 추가 설명:** 강의에서는 `h1`을 문서에서 한 번만 사용하고 `h2`, `h3` 순서로 제목을 사용하도록 안내했습니다. HTML 문법 자체가 `h1`의 복수 사용을 금지하는 것은 아니지만, 제목의 의미와 계층을 일관되게 구성하는 것이 중요합니다.

### 2. 이미지 크기와 object-fit

원본 이미지가 브라우저 너비보다 크면 가로 스크롤이 생길 수 있습니다. 강의에서는 배너 이미지에 아래 속성을 적용합니다.

```css
.banner img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

- `width: 100%;` — 부모 요소의 너비를 채웁니다.
- `height: 100%;` — 부모 요소의 높이를 채웁니다.
- `object-fit: cover;` — 이미지 원본 비율을 유지하며 영역을 채우고, 넘치는 부분을 잘라냅니다.

`object-fit: fill`은 이미지가 찌그러질 수 있고, `contain`은 이미지 전체를 보이게 하지만 빈 공간이 생길 수 있습니다.

### 3. Flexbox 부모와 자식

```css
.product-list {
  display: flex;
  gap: 18px;
}

.product-card {
  flex-grow: 1;
  flex-basis: 0;
}
```

- **Flex 컨테이너:** `display: flex`를 적용한 부모 `.product-list`
- **Flex 아이템:** 그 바로 아래 자식 `.product-card`
- `gap`은 카드 사이의 간격이므로 부모에 지정합니다.
- `flex-grow`는 남는 공간의 분배 비율입니다.
- `flex-basis`는 공간 분배 전 기준 크기입니다.

**강사님 강조:** `flex-grow: 1`과 `flex-basis: 0`을 함께 사용하는 방식을 기억하도록 안내했습니다.

> **준비:** 이전 교시까지 만든 프로젝트를 VS Code에서 열고 기존 상단 영역 코드는 유지합니다. 여기서는 파일명을 `index.html`, `style.css`로 가정합니다. 실제 파일명이 다르면 기존 파일을 사용하세요.

### 실습 1. 상단 영역을 `<header>`로 묶기

1. VS Code에서 `index.html`을 엽니다.
2. `Ctrl + Home`으로 파일 위로 이동합니다.
3. `<body>` 태그를 찾습니다.
4. 기존 상단 배너 코드 위에 커서를 놓습니다.
5. `header`를 입력한 뒤 `Tab`을 누릅니다.
6. 생성된 `<header></header>`를 여러 줄로 벌립니다.
7. 기존 상단 배너·유틸리티 메뉴·메인 헤더 영역 전체를 **여는 태그부터 대응되는 닫는 태그까지** 선택합니다.
8. `Alt + ↑`를 이용해 선택한 줄을 옮기거나 `Ctrl + X`로 잘라낸 뒤 `<header>` 안에 `Ctrl + V`로 붙여넣습니다.
9. `Tab`으로 들여쓰기를 정리하고 `Ctrl + S`로 저장합니다.

Emmet 입력:

```text
header
```

`Tab`을 누르면:

```html
<header></header>
```

기존 구조의 **설명용 예시**:

```html
<body>
  <div class="top-banner">...</div>
  <div class="utility-menu">...</div>
  <div class="main-header">...</div>
</body>
```

이동 후 목표 구조:

```html
<body>
  <header>
    <div class="top-banner">...</div>
    <div class="utility-menu">...</div>
    <div class="main-header">...</div>
  </header>
</body>
```

**주의:** `Alt + ↑`는 선택된 코드의 줄을 위로 옮기는 기능이지 자동으로 부모 태그 안에 감싸는 기능은 아닙니다. 이동 후 태그의 위치를 반드시 확인합니다.

### 실습 3. 배너 박스와 이미지 만들기

**1단계: HTML 배너 박스**

`index.html`의 `<main>` 안에 `.banner`를 입력하고 `Tab`을 누릅니다.

```html
<div class="banner"></div>
```

**2단계: CSS 배너 영역 확인**

`style.css`에서 기존 규칙 아래에 작성합니다.

```css
.banner {
  background-color: gray;
  height: 370px;
}
```

저장 후 Live Server 화면에서 회색 영역이 나타나는지 확인합니다.

**3단계: 이미지 추가**

`.banner` 여는 태그와 닫는 태그 사이에 `img`를 작성합니다.

```html
<div class="banner">
  <img src="../images/banner/1.jpg" alt="배너 이미지">
</div>
```

여기의 `src`는 **설명용 예시 경로**입니다. 강의에서는 상위 폴더→이미지 폴더→배너 폴더에서 1~3번 이미지 중 하나를 선택했습니다. 실제 경로와 확장자는 프로젝트 탐색기에서 확인하세요.

- `src`: 이미지 파일 주소
- `../`: 한 단계 위 폴더
- `alt`: 이미지 대체 텍스트

**4단계: 이미지가 넘치거나 찌그러지는 문제 수정**

`style.css`에 다음 코드를 추가합니다.

```css
.banner img {
  width: 100%;
  height: 100%;
  object-fit: cover;
}
```

**직접 실험:** `object-fit` 값을 `fill`, `contain`, `cover`로 차례로 바꾸고 저장해 이미지가 어떻게 달라지는지 확인합니다. 배너 `height: 370px`도 임시로 `200px`로 바꿔보세요. 실험 후 원래 값으로 복원합니다.

### 실습 6. 제목과 설명 만들기

**1단계:** `index.html`의 `.product-header` 안에 다음 코드를 작성합니다.

```html
<div class="product-header">
```

강사는 제목 태그와 문단 태그의 클래스명을 AI에게 추천받아 적용하게 했습니다. 여기의 `product-title`, `product-description`은 정리본에서 통일한 예시 클래스명입니다.

**2단계:** `style.css` 위쪽에서 기본 여백을 초기화합니다.

```css
h1, h2, h3, h4, h5, h6, p {
  margin: 0;
}

p {
  font-size: inherit;
  font-weight: normal;
}
```

기본 제목·문단 여백을 제거할 목적이라면 `margin: 0`이 적절합니다. `inherit`는 부모의 값을 상속하며 항상 16px을 의미하지 않습니다.

**3단계:** 제목/설명 중앙 정렬

```css
.product-header {
  text-align: center;
}
```

**4단계:** 제목 아래 간격 8px

```css
.product-title {
  padding-bottom: 8px;
}
```

**5단계:** 설명과 상품 목록 사이 간격 23px

```css
.product-list {
  padding-top: 23px;
}
```

### 실습 7. `.con` 컨테이너로 묶기

`index.html`의 `.product` 내부에 `.con`을 추가해 제목과 목록을 감쌉니다.

```html
<section class="product">
```

강의에서는 기존 Flex 설정 때문에 내용이 가로로 배치되어 `flex-direction: column`으로 수정했습니다.

```css
.product .con {
  flex-direction: column;
}
```

**확인:** 이 규칙이 작동하려면 `.con`에 이미 `display: flex` 또는 `inline-flex`가 적용되어 있어야 합니다. 기존 수업의 `.con`을 유지하세요.

### 실습 8. 상품 카드 네 개 만들기

**1단계: Emmet 작성**

`index.html`의 `.product-list` 내부에서 다음을 입력합니다.

```text
.product-card{상품 $}*4
```

`Tab`을 누르면:

```html
<div class="product-card">상품 1</div>
<div class="product-card">상품 2</div>
<div class="product-card">상품 3</div>
<div class="product-card">상품 4</div>
```

- `{상품 $}`: 각 태그 안에 상품 번호를 표시할 텍스트
- `$`: 반복할 때 1, 2, 3, 4처럼 번호 증가
- `*4`: 4개 반복 생성

**2단계: 임시 회색 배경**

```css
.product-card {
  background-color: gray;
}
```

**3단계: 카드 부모에 Flex와 간격 적용**

```css
.product-list {
  padding-top: 23px;
  display: flex;
  gap: 18px;
}
```

**4단계: 각 카드에 같은 성장 비율 적용**

```css
.product-card {
  background-color: gray;
  flex-grow: 1;
  flex-basis: 0;
}
```

카드의 너비가 같고 사이 간격은 18px이면 성공입니다.

## ⑤ 코드 한 줄씩 해설

| 기호 | 이름 | 역할 |
|---|---|---|
| `< >` | 꺾쇠괄호 | HTML 태그를 표현 |
| `/` | 슬래시 | `</div>`와 같은 닫는 태그 표시 |
| `=` | 등호 | 속성에 값 지정 |
| `" "` | 큰따옴표 | 속성값 구분 |
| `.` | 점 | CSS 클래스 선택자 |
| `#` | 샵 | CSS ID 선택자 |
| `{ }` | 중괄호 | CSS 규칙의 선언 블록 |
| `:` | 콜론 | 속성명과 속성값 구분 |
| `;` | 세미콜론 | CSS 선언의 끝 |
| `%` | 퍼센트 | 기준 크기에 대한 비율 |
| `px` | 픽셀 | CSS 길이 단위 |

다음 코드를 다시 보겠습니다.

```css
.product-card {
  flex-grow: 1;
  flex-basis: 0;
}
```

- `.product-card`: `class="product-card"`인 HTML 요소를 선택합니다.
- `{`: 해당 선택자에 적용할 속성 선언의 시작입니다.
- `flex-grow: 1;`: Flex 컨테이너의 남는 공간을 1의 비율로 나눠 갖도록 합니다.
- `flex-basis: 0;`: 공간을 나누기 전 기준 크기를 0으로 설정합니다.
- `}`: 해당 CSS 규칙의 끝입니다.

### 부모와 자식 구조

```text
.product-list  ← 부모 / display: flex와 gap: 18px
├── .product-card  ← 자식 / flex-grow: 1; flex-basis: 0
├── .product-card  ← 자식 / flex-grow: 1; flex-basis: 0
├── .product-card  ← 자식 / flex-grow: 1; flex-basis: 0
└── .product-card  ← 자식 / flex-grow: 1; flex-basis: 0
```

### VS Code에서 직접 해볼 CSS 실험

채팅창에 제공했던 인터랙티브 미리보기는 일반 Markdown 파일에 그대로 삽입할 수 없으므로 **실험 과제**로 바꿨습니다.

1. `object-fit: cover`를 `fill`, `contain`으로 변경해 차이를 확인합니다.
2. `.banner`의 `height`를 `370px`에서 `200px`로 바꿉니다.
3. `.product-list`의 `gap`을 `0`, `18px`, `30px`으로 차례로 바꿉니다.

```html
<div class="product-info"></div>
```

**`+` 기호**는 같은 부모 안에 형제 요소를 나란히 만든다는 뜻입니다.

이미지 박스에 이미지 태그를 추가합니다.

```html
<div class="product-card">
  <div class="product-image">
    <img src="" alt="상품 이미지">
  </div>
  <div class="product-add"></div>
  <div class="product-info"></div>
</div>
```

> **초보자를 위한 추가 설명:** 현재 `src`는 비어 있습니다. 실제 프로젝트에서는 이미지 폴더에 존재하는 파일 경로로 바꾸어야 사진이 나옵니다.

### STEP 3. 주황색 임시 배경 설정

`style.css`를 열고 아래 코드를 해당 선택자 부분에 추가합니다.

```css
.product-image {
  background-color: orange;
}

.product-add {
  background-color: orange;
}

.product-info {
  background-color: orange;
}
```

세 영역이 제대로 잡혔는지 확인하기 위한 **임시 색상**입니다. 최종 단계에서는 삭제합니다.

### STEP 4. 담기 영역 위아래 여백

`style.css`의 `.product-add`에 다음을 추가합니다.

```css
.product-add {
  background-color: orange;
  padding-top: 6px;
  padding-bottom: 8px;
}
```

- `padding-top: 6px;`: 위쪽 안쪽 여백 6px
- `padding-bottom: 8px;`: 아래쪽 안쪽 여백 8px

**강사님이 강조한 점:** 이 구현은 영역의 공간을 잡는 방법이지만 클릭 영역과 간격을 정교하게 분리하는 구현은 아닙니다. 이번 평가 준비에서는 여기까지만 진행했습니다.

### STEP 5. 상품 이미지 넣고 너비 맞추기

1. `index.html`에서 `.product-image` 안의 `img` 태그로 이동합니다.
2. `src`에 이미지 폴더 안의 실제 상품 이미지 경로를 넣습니다.
3. `style.css`에서 다음 CSS를 추가합니다.

```css
.product-image img {
  width: 100%;
}
```

`.product-image img`는 `.product-image` **안에 있는** `img`를 선택합니다. 이미지 너비가 부모 영역에 맞춰집니다. 강사님은 이 사례에서 높이를 별도로 맞출 필요가 없다고 설명했습니다.

**강의 확인 실습:** 이미지 태그에 `background-color: red;`를 잠시 적용해 남는 공간이 있는지 확인하고, 확인 후 빨간색을 삭제했습니다.

> **초보자를 위한 추가 설명:** 이미지가 인라인 요소로 배치되어 이미지 아래에 미세한 공간이 보이면 `display: block;`을 검토할 수 있습니다.

### STEP 6. 담기 버튼 만들고 기본 스타일 초기화

`index.html`에서 `.product-add` 내부에 버튼을 추가합니다.

```html
<div class="product-add">
  <button type="button"></button>
</div>
```

`type="button"`은 폼을 제출하지 않는 일반 버튼입니다.

강사님은 AI에게 버튼 초기화(normalize) CSS를 요청했습니다. 아래는 강의에서 언급된 **5개 속성을 바탕으로 재구성한 예시**입니다.

```css
button {
  margin: 0;
  padding: 0;
  border: 0;
  background: none;
  color: inherit;
}
```

| 속성 | 뜻 |
|---|---|
| `margin: 0;` | 바깥 여백 초기화 |
| `padding: 0;` | 안쪽 여백 초기화 |
| `border: 0;` | 기본 테두리 제거 |
| `background: none;` | 기본 배경 제거 |
| `color: inherit;` | 부모의 글자색 상속 |

> **주의:** `button` 선택자는 페이지의 모든 버튼에 영향을 줄 수 있습니다. 이미 만든 다른 버튼도 확인하세요.

### STEP 7. 장바구니 아이콘 + 담기 텍스트

강사님은 앞에서 사용한 장바구니 아이콘 코드를 복사하여 버튼 안에 넣었습니다.

아래 코드는 구조 설명용 예시입니다.

```html
<div class="product-add">
  <button type="button" class="add-btn">
    <!-- 기존 프로젝트에서 복사한 장바구니 아이콘 코드 -->
    <span>담기</span>
  </button>
</div>
```

`span`은 글자를 묶어 별도 스타일을 적용할 때 편리합니다. 아이콘과 텍스트를 구분해 관리할 수 있습니다.

> **초보자를 위한 추가 설명:** 아이콘 태그 옆에 텍스트를 직접 적어도 HTML 문법상 가능합니다. 글자를 반드시 `span`으로 감싸야 하는 것은 아니지만, 스타일을 개별적으로 조절하기 편리합니다.

### STEP 8. 아이콘 크기 조정

상단의 큰 장바구니 아이콘 스타일과 상품 카드의 아이콘 스타일은 서로 구분해야 합니다. 강의에서는 상품 카드 안의 아이콘을 **20px**로 조정했습니다.

```css
.product-add #shopping {
  font-size: 20px;
}
```

> 위 코드는 아이콘에 실제로 `id="shopping"`이 있을 때 적용되는 **설명용 예시**입니다. 기존 프로젝트의 아이콘 코드를 확인하세요.

강사님은 버튼에 `add-btn` 클래스를 추가해 버튼 스타일을 구분했습니다.

### STEP 9. Flexbox 중앙 정렬

`style.css`에서 `.add-btn`에 아래 코드를 추가합니다.

```css
.add-btn {
  display: flex;
  align-items: center;
}
```

- `display: flex;`: 자식 요소를 플렉스 방식으로 배치합니다.
- `align-items: center;`: 기본 가로 Flexbox의 **세로 방향**으로 가운데 정렬합니다.

강의 후반에 버튼 내부를 가로로도 가운데로 맞추기 위해 `justify-content: center;`를 추가합니다.

> 아래 종합 실습에서는 보충 예시로 `font-size: 16px`과 `gap: 2px`을 사용합니다.

### STEP 10. 임시 배경 제거 및 담기 버튼 디자인

1. `.product-add`에 있던 `background-color: orange;`를 삭제합니다.
2. `.product-image`의 임시 배경색을 삭제합니다.
3. `.product-card`의 임시 회색 배경은 강의처럼 주석 처리합니다.
4. `.add-btn`에서 테두리·너비·높이·둥근 모서리를 설정합니다.

```css
.add-btn {
  display: flex;
  align-items: center;
  justify-content: center;

  width: 100%;
  height: 36px;

  border: 1px solid #ddd;
  border-radius: 4px;
}
```

**강의에서 확인되는 값:** 버튼 높이 `36px`, 너비 `100%`, 테두리 두께 `1px`, 모서리 `4px`.

> 원래 수업에서 받은 색상값이 있다면 그것을 사용하세요.

**CSS 속성별 역할**

| 속성 | 역할 |
|---|---|
| `width: 100%` | 부모 너비에 맞추기 |
| `height: 36px` | 버튼 높이 지정 |
| `border: 1px solid` | 1px 실선 테두리 |
| `justify-content: center` | 기본 가로 Flexbox의 가로 중앙 정렬 |
| `align-items: center` | 세로 중앙 정렬 |
| `border-radius: 4px` | 모서리 둥글게 |

### STEP 11. 이미지 모서리 자르기

강사님은 `img` 태그가 아닌 이미지의 **부모 박스**인 `.product-image`에 둥근 모서리와 넘침 숨김을 적용했습니다.

```css
.product-image {
  border-radius: 4px;
  overflow: hidden;
}
```

- `border-radius: 4px;`: 이미지 박스의 모서리를 둥글게 만듭니다.
- `overflow: hidden;`: 둥근 부모 박스 밖으로 넘치는 자식 이미지 부분을 숨깁니다.

**기억할 내용:** `border-radius`만으로는 기대한 모양으로 잘리지 않을 수 있습니다. 부모 박스에 `overflow: hidden;`을 함께 설정하는 방법을 익혀 두세요.

### STEP 12. 상품 정보 문단 세 개 만들기

`index.html`에서 `.product-info` 안에 커서를 놓고 Emmet을 입력합니다.

```text
p*3
```

확장 결과:

```html
<p></p>
<p></p>
<p></p>
```

강사님은 AI에게 적절한 클래스명을 추천받았고, 마지막 줄에 나란한 정보 두 개는 `span`을 사용했습니다.

```html
<div class="product-info">
  <p class="product-name">신선한 제철 과일</p>
  <p class="product-price">12,800원</p>
  <p class="product-original">
    <span class="product-discount">20%</span>
    <span class="original-price">16,000원</span>
  </p>
</div>
```

- `p`: 문단을 만드는 블록 요소로, 기본적으로 줄을 차지합니다.
- `span`: 짧은 정보를 나란히 표시하거나 따로 스타일링하는 데 적합한 인라인 요소입니다.

**원본 확인 필요:** 실제 세 줄의 텍스트와 배치 순서는 영상 또는 기존 프로젝트 파일에서 최종 확인해야 합니다.

### STEP 13. 상품 정보의 글자 스타일과 여백

```css
.product-original {
  padding-top: 8px;
  padding-bottom: 7px;
}

.product-discount {
  padding-right: 8px;
}
```

`.product-info`에 임시로 넣은 `background-color: orange;`도 삭제합니다.

### AI에게 반복 작업 맡기기

**AI 요청문 예시:**

> 첫 번째 `product-card`의 HTML 구조와 CSS 클래스는 유지하고, 두 번째부터 네 번째 `product-card`의 상품 이미지 경로, 상품명, 가격, 할인 정보만 각각 다르게 변경해 줘. 기존 레이아웃이나 다른 영역은 수정하지 마.

AI 수정 뒤 직접 확인할 사항:

- [ ] 이미지 경로가 실제 프로젝트에 존재하는가?
- [ ] `.product-image img`의 `width: 100%`가 적용되었는가?
- [ ] 네 카드가 모두 표시되는가?
- [ ] 상품명·가격이 서로 맞게 변경되었는가?
- [ ] 임시 주황색·빨간색 스타일을 지웠는가?

**강사님 강조:** AI는 반복적이고 번거로운 작업을 돕는 도구입니다. **본인이 직접 HTML/CSS를 작성할 수 있어야 합니다.**

## ⑨ 최종 종합 실습 — 빈 파일에서 상품 카드 만들기

> **초보자를 위한 추가 설명:** 아래는 기존 마켓컬리 프로젝트를 망가뜨리지 않고 연습하기 위한 **독립형 교육용 예시**입니다.

### 파일 만들기

1. VS Code에서 새로운 `product-practice` 폴더를 엽니다.
2. 탐색기에서 `index.html`, `style.css` 파일을 만듭니다.
3. `index.html`에서 `!`를 입력하고 Emmet으로 HTML 기본 구조를 생성합니다.
4. `<head>` 안에 아래 연결 코드를 추가합니다.

```html
<link rel="stylesheet" href="style.css">
```

### 폴더 구조

```text
product-practice/
├── index.html
└── style.css
```

### 순서대로 직접 작성하기

1. `<body>` 안에서 `.product-card`를 생성합니다.
2. 카드 안에 `.product-image`, `.product-add`, `.product-info` 세 박스를 만듭니다.
3. 이미지 영역에 `<img>`를 넣습니다.
4. 담기 영역에 `button`과 `span`을 넣습니다.
5. 상품 정보 영역에 `p` 태그 세 개를 넣습니다.
6. `style.css`에서 `width`, `padding`, `display: flex`, `border`, `border-radius`, `overflow`를 설정합니다.
7. 저장한 뒤 Live Server에서 확인합니다.
8. 완성한 카드를 세 번 더 복사해 네 개를 구성합니다.

### 최종 실습 전체 코드 — `index.html`

```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>상품 카드 실습</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main class="product-list">
    <div class="product-card">

      <div class="product-image">
        <img
          src="https://placehold.co/300x380/png"
          alt="상품 이미지 예시">
      </div>

      <div class="product-add">
        <button type="button" class="add-btn">
          <span aria-hidden="true">🛒</span>
          <span>담기</span>
        </button>
      </div>

      <div class="product-info">
        <p class="product-name">신선한 제철 과일</p>
        <p class="product-price">12,800원</p>
        <p class="product-original">
          <span class="product-discount">20%</span>
          <span class="original-price">16,000원</span>
        </p>
      </div>

    </div>
  </main>
</body>
</html>
```

### 최종 실습 전체 코드 — `style.css`

```css
* {

}

}

}

  padding-top: 6px;
  padding-bottom: 8px;
}

.add-btn {
  display: flex;
  align-items: center;
  justify-content: center;
  gap: 2px;
  width: 100%;
  height: 36px;
  border: 1px solid #ddd;
  border-radius: 4px;

  font-size: 15px;

  padding-top: 7px;
}
```

> **초보자를 위한 추가 설명:** `box-sizing`, `display: block`, `gap`, `cursor` 등은 독립 실습을 위해 보충한 속성입니다. `https://placehold.co/...`는 외부 예시 이미지 주소이며 인터넷이 연결되어 있어야 표시됩니다. 본인의 이미지 폴더에 실제 상품 사진을 넣고 경로를 바꾸어도 됩니다.

## ⑩ 핵심 요약과 체크리스트

| 개념 | 기억할 코드 |
|---|---|
| 이미지 너비 맞추기 | `width: 100%;` |
| 위쪽 안쪽 여백 | `padding-top: 6px;` |
| 아래쪽 안쪽 여백 | `padding-bottom: 8px;` |
| Flexbox | `display: flex;` |
| 가로 중앙 정렬 | `justify-content: center;` |
| 세로 중앙 정렬 | `align-items: center;` |
| 담기 버튼 높이 | `height: 36px;` |
| 모서리 둥글게 | `border-radius: 4px;` |
| 넘치는 부분 숨기기 | `overflow: hidden;` |
| 문단 세 개 Emmet | `p*3` |
